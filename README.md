# MINFO

MINFO（Music Information）用于在浏览器中整理本地音频文件的元数据。选择文件后，可以编辑标签、封面和歌词，并下载一个新的音频文件；源文件不会被上传或就地修改。

## 使用方式

1. 把一个或多个音频文件拖入页面，或点击“选择音频文件”。队列会按顺序读取每个文件。
2. 在“格式与输出”中选择保持原格式、MP3、M4A 或 AAC，并按需调整输出文件名和转码质量。
3. 编辑需要的元数据。可管理标题、艺术家、专辑、流派、曲目、评论、作曲者、封面和按语言区分的歌词。
4. 查看导出预检。若目标格式会限制字段或可能造成兼容性差异，先阅读说明，再勾选“我已知晓，坚持导出”。
5. 点击“导出文件”。浏览器会下载新副本，默认文件名为 `{源文件名} (MINFO).{扩展名}`。

### 歌词

- 每种语言只能保留一个歌词槽位；可新增、编辑或删除槽位。
- 当前表单中的歌词槽位就是导出结果：删除某种语言后，新文件不会保留该语言已识别的旧歌词。
- 每个槽位可通过“解析歌词文件”导入不超过 2 MB 的 `.txt`、`.lrc` 或明文 `.qrc` 文件。文本在浏览器本地读取；已有歌词时，必须再次确认才会替换当前槽位。
- 明文 QRC 的逐字时间会转换为 LRC 行级时间标签；加密或无法识别的 QRC、空文件、错误编码和不受支持的扩展名会保留当前歌词并给出就地错误说明。
- LRC 时间标签可在预览中展开查看；编辑器会保留你输入的歌词原文。

### 导出提示

- 页面会在导出前显示当前格式、字段限制和兼容性风险。请以该提示为准。
- 部分格式或字段无法由浏览器可靠处理时，可以使用“复制 FFmpeg 命令”在本机继续执行。
- 导出失败不会清空当前草稿；修改后可直接重试。

## 本地运行

需要 Node.js 22.18 或更高版本，以及 pnpm 12.6.0。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

生产构建和完整校验：

```bash
pnpm build
```
